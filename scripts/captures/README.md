# Screenshot recipes

Every product picture on the site is the real app, captured from its own
repository at a release. These are the recipes, so an update can be made again
instead of rediscovered. Each writes PNG or WebP files; convert to WebP at
quality 82 into `public/assets/` where needed, then run `npm run assets:images`
(the 900w/1200w variants) and, when a product's look changed, `npm run assets:og <slug>`.
Board games (Chessboard, Goban) have their own committed scripts:
`scripts/board-apps.mjs`, `capture-board-screenshots.mjs`, `record-board-demos.mjs`.
